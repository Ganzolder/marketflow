# **App Name**: MarketFlow

## Core Features:

- Управление Кампаниями: Создание и редактирование маркетинговых кампаний, включая установку бюджетов, активностей и целей.
- Панель управления кампанией: Просмотр деталей кампании с целями (например, предзаказы, упоминания в СМИ, трафик на сайт) и текущим прогрессом. Редактирование целей должно быть доступно во время создания и изменения.
- Управление активностями: Добавление активностей в кампании (например, реклама на радио), указание целей, плановых показателей и фактических метрик для каждой цели.
- Отслеживание активностей: Отслеживание статусов активностей: запланирована, выполняется, завершена. Отображение предстоящих и текущих активностей.
- Сохранение данных: Хранение всей информации о кампаниях и активностях в базе данных Firebase.
- Боковое меню: Боковое меню должно содержать сводную информацию: кампании, акции, активности, калькулятор расчета акций и генератор креативов.
- Генератор креативов: Генератор креативов для маркетинговых кампаний. LLM tool used to suggest novel content.
- Калькулятор акций: Калькулятор расчета эффективности маркетинговых акций.

## Style Guidelines:

- Основной цвет: Яркий фиолетовый (#A050BE), чтобы передать креативность и энергию в маркетинге.
- Цвет фона: Светло-серый (#F0F0F2), обеспечивающий чистый и нейтральный фон.
- Акцентный цвет: Бирюзовый (#30BF90), привлекающий внимание к призывам к действию и индикаторам прогресса.
- Шрифт: 'Inter' (sans-serif) для четкой и профессиональной читаемости всей информации о кампаниях и деталях активностей. Подходит как для заголовков, так и для основного текста.
- Используйте четкие и лаконичные значки для статуса кампании, типов активностей и показателей целей.
- Используйте сеточный макет для представления кампаний и активностей в организованном виде.
- Внедрите тонкие переходы и анимации для улучшения пользовательского опыта при навигации между кампаниями и активностями.
